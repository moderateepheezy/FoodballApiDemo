# Foodball API Demo

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/moderateepheezy/FoodballApiDemo.git
   ```

2. Navigate to the project directory:
   ```bash
   cd FoodballApiDemo
   ```

3. Open the project in Xcode:
   ```bash
   open "SterlingBank Interview.xcworkspace"
   ```

4. Install dependencies via CocoaPods:
   ```bash
   pod install
   ```

5. Build and run:
   - Choose a simulator or device in Xcode.
   - Press `Cmd + R` or click the play button to build and run the app.
